How to check a Do Not Stop code yourself

Codes pages go stale fast. Instead of trusting any list, including ours, here is the short routine the fan site Do Not Stop Wiki uses, so you can check a code in two minutes.

Step 1: find where the code is printed

The developer posts codes in the Roblox game description first. As of November 10, 2026 the description lists RELEASE, LASTSTOP, DONOTSTOP and ROUTE1610 with their rewards: 250, 250, 200 and 150 credits. Rewards are credits only.

Step 2: see if a player has entered it

A code that appears on a player's screen is stronger evidence than one in a description. On the codes page, RELEASE and DONOTSTOP are marked Checked because they appear in a player's code box in the garage; LASTSTOP and ROUTE1610 are marked as only seen in the description.

Step 3: redeem it

Load into the lobby, open the Garage, choose the Codes tab (the fifth one) and type the code in the box, then press Redeem. The box itself says the codes are in the game's description. Total if all four work: up to 850 credits, as the credits page adds up.

Do not mix up Last Stop

Last Stop is a different Roblox game, and its codes do not work in Do Not Stop. The code LASTSTOP in our list is a Do Not Stop code that happens to share the word.

How the site labels what it knows

The About page explains the sources: player videos on YouTube, with whose video and which day, the game's own Roblox description and game pass descriptions, and Roblox's public data for player counts and visits. When the game shows no number, the site writes "not shown in game". Each page lists its sources at the bottom, and every fix goes into the updates log.

If a code fails

Send the page and the code to the support address on the About page. Fixes are made the same day, and the site then adds a line to the log with the date. This is the whole point of the Checked and Player reported labels: they tell you whether the site tried a code itself or only saw it in a video. At the moment the site has not redeemed any of the four codes on its own account, and it says so on the codes page in plain words. That honesty is a feature, because a list that claims to have tested everything on day one is usually copying another list. Until a code is marked Checked, treat it as a maybe, and keep in mind that credits are the only reward any listed code gives (no skins, no cars); it costs nothing to try, but do not plan a purchase around credits you have not seen arrive. For what credits buy, the shop and crates page lists prices that were readable in footage.
